# Концепции редизайна «Графика приступов»

- [`e-calm-plus.html`](./e-calm-plus.html) — **утверждённый макет** редизайна «Спокойный день+». По нему сделаны веб-интерфейс (светлая тема, токены в `resources/css/app.css`) и мобильное приложение (токены в `mobile/src/theme/tokens.ts`).
- `a-diary.html` («Дневник»), `b-calm.html` («Спокойный день»), `c-chronicle.html` («Хроника»), `d-hybrid.html` («Дневник+») — **отвергнутые варианты**, сохранены для истории решения. Не использовать как референс для реализации.
- [`index.html`](./index.html) — страница сравнения концепций (исходный обзор направлений, не актуальна после утверждения макета).
