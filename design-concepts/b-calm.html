B — «Спокойный день»

Продукт — это тихий помощник, а не таблица. Главное действие — «записать приступ» — всегда под рукой и самое заметное на экране; журнал вторичен, он аккуратно собран ниже. Мягкая светлая зелёно-бирюзовая гамма, много воздуха, один тёплый акцент.

Впечатление и идея

Что чувствует пользователь

Безопасность и ясность. Если человек открывает приложение в тревожный момент, он сразу видит одну большую кнопку и не ищет «+» в углу.

Главная композиция

Сверху — «паспорт состояния»: сколько дней без записей, неделя точками, и кнопка «Записать приступ». Ниже — сгруппированный по дням список в белых «листах». Экспорт уходит во вторичное меню.

Характер

Современная «wellness»-эстетика без излишеств: один шрифт, один основной цвет, тёплое жёлто-оранжевое пятно только там, где есть события.

Важно: «дней без записей» и «неделя точками» — новые вычисляемые блоки, но они считаются из тех же записей API без новых данных. Если такой акцент нежелателен (счётчик «дней без приступов» может быть эмоционально тяжёлым), блок убирается, остальная концепция сохраняется.

Компоненты

7 дней30 дней

Кнопки

Радиус 10–16 px, главная «Записать» — крупная (60 px высотой), остальные компактные. Основной цвет — бирюзовый.

Карточки и поля

Белые «листы» только для групп записей (одна на день), не для каждой строки. Поля с рамкой 1.5 px и подписью-ярлыком внутри.

Иконки и иллюстрации

Линейные, 1.75 px, с подписями в нижней панели. Иллюстрация одна — спокойное пустое состояние.

Тени, скругления, анимации

Тень только у нижней «шторки» и активного переключателя. Радиусы 10 / 16 / 24 по уровню. Анимации: шторка выезжает, точка недели «вспыхивает» при записи.

Свободное пространство

Воздух вокруг главного действия; плотность списка умеренная — 56–64 px на запись.

Адаптив

Десктоп: закреплённая левая панель + список. Телефон: панель сворачивается в верхний блок, «Новая запись» — нижняя шторка вместо отдельного экрана.

Плюсы и минусы

Сильные стороны

  • Лучшая эргономика главного действия — «записать» за одно касание
  • Выглядит современно и привычно, не пугает
  • Хороший обзор недели без графиков

Возможные недостатки

  • Ближе всего к «типичному wellness-приложению» — меньше оригинальности
  • Блок «дней без приступов» нужно согласовать по тону
  • Больше всего новой вёрстки: панель, неделя, шторка
